# Figure and diagram style

Apply these rules whenever creating or revising a chart, paper figure, or system diagram for this project. Follow the supplied reference for label placement and visual hierarchy.

- Put short black axis labels next to the ticks. Place the horizontal axis label below the plot and rotate the vertical axis label beside the plot. Include units in the axis label when applicable, such as `End-to-end latency (s)`.
- In system diagrams, use short labels for components and label arrows only when the flow needs clarification.
- Omit gray explanatory subtitles, decorative labels, and fragments strung together with middle dots or commas. Keep the legend and annotations needed to read the data.
- Put sample sizes, experiment details, and marker explanations in the figure caption. If an explanation must appear inside the figure, write it as one short sentence.
