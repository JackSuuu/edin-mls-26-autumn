# Results and Analysis 写作规则

适用于报告第 4 节和所有 4.x 小节。正文用平实的技术英语。

- 标题尽量写该节发现的结果或权衡。正文开头交代该比较验证什么，或直接给出最重要的发现。
- 图表保存完整数值。正文只引用支撑判断的数字，说明图中出现了什么模式、这个模式提示了什么、对照实验验证了哪一部分。引用具体面板，方便读者核对。
- 区分由现象提出的解释与实验证据。交代统计不确定性、计时边界和未测配置。证据不足时写没有观察到明确的收益，点估计的小变动按其实际大小表述。
- 把实验串起来。解释上一组结果为什么值得做下一组对照，以及下一组改变了哪项输入、方法或成本。
- 写成本与收益时标明量纲及分母。区分每题有没有首次命中、平均文档召回率、归一化 judge 分和请求延迟。

## 4.1 的例子
